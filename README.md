# 小黑盒抽卡记录查询插件 (xhh_gacha)

通过小黑盒接口查询米哈游系游戏（原神、崩铁、绝区零、异环等）的抽卡记录。

## 功能

- `/xhh 绑定 <user_pkey>` — 绑定小黑盒账号（按用户隔离，群聊/私聊均可用）
- `/xhh 解绑` — 解绑小黑盒账号
- `/xhh 记录 [游戏ID]` — 查询抽卡记录
- `/xhh 统计 [游戏ID]` — 统计抽卡数据
- `/xhh 帮助` — 查看插件帮助

游戏ID: `1`=原神 `2`=崩铁 `3`=绝区零 `4`=异环 `5`=无限暖暖

## 安装

1. 将 `xhh_gacha` 目录放入 AstrBot 的 `plugins/` 目录
2. 在 WebUI 中启用插件
3. 在插件的「配置」弹窗中填入你抓包得到的小黑盒 API 接口地址和请求头（配置项定义见 `_conf_schema.json`）

## 获取 user_pkey

1. 浏览器打开 [小黑盒网页版](https://xiaoheihe.cn) 并登录
2. 按 `F12` 打开开发者工具
3. 切换到 **Application/存储** 标签（或 Network 标签下任意请求的请求头中）
4. 在 **Cookie** 中找到 `user_pkey` 的值

## 获取真实 API 接口

小黑盒没有公开的抽卡记录 API，需要自行抓包：

1. 登录小黑盒网页版
2. 打开开发者工具的 **Network** 标签
3. 在小黑盒网页中打开"抽卡记录"页面
4. 找到对应的网络请求（如 `/gacha/...`）
5. 复制请求 URL 和请求头，分别填入插件的 `api_list_gacha_url` 和 `headers_json` 配置项中

> ⚠️ 注意：小黑盒接口属于非公开接口，接口地址和参数格式可能随时变化。如果查询失败，请重新抓包确认接口 URL、请求头、Cookie 等信息。

## 配置项说明

| 配置项 | 说明 |
|-------|------|
| `api_list_gacha_url` | 抽卡记录查询接口 URL |
| `headers_json` | 请求头（JSON 格式），从抓包中获取 |
| `use_pkey_as_auth` | 是否将 user_pkey 放入 `Authorization` 头（默认 false，使用 `x-user-token` 头） |
| `default_game_id` | 默认查询的游戏 ID（默认 4=异环） |
| `limit` | 单次请求最大条数（默认 50） |

> 配置通过 `_conf_schema.json` 定义，AstrBot 会据此在 WebUI 中生成配置表单，配置文件保存在 `data/config/xhh_gacha_config.json`。

## 解析逻辑说明

由于小黑盒接口返回的数据结构可能变化，插件当前会先以原始 JSON 形式返回结果。你可以根据实际抓包返回的数据结构，修改 `main.py` 中的解析逻辑，实现以下高级功能：

- 按卡池分类展示（角色池/武器池/常驻池）
- 统计五星出货率、保底计数、歪了没
- 生成长图分享抽卡结果

## 隐私说明

- 用户的 user_pkey 仅存储在本地的 AstrBot 数据库中，不会被发送到除小黑盒 API 之外的任何地方
- 每个用户可以绑定各自的小黑盒账号（按消息发送者 ID 隔离）
